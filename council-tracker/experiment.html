The Experiment

BUILD STAGE

The Experiment is still under construction. Machinery described here is developmental and must not be treated as a completed, validated or operational experimental system.

A controlled test of whether useful investigative structure can be derived from authoritative source material without preloading the subject matter.

Plain-language rule

The experiment begins without substantive prior knowledge. The machinery must demonstrate what it can derive from supplied source material while preserving the difference between source evidence, derived structure, verification and publication.

Question being tested

Can a general-purpose evidence system begin from a zero-information state, ingest an explicitly supplied authoritative source, preserve what it receives, derive useful relationships from the source itself, and progress toward verified public information without being told in advance what issues, people, places or outcomes to look for?

Controls

No substantive subject, locality, matter, actor, issue list, historical register, glossary or inherited dataset is preloaded. Existing Council Tracker material, previous public registers and other investigative material are not inputs to the experimental machinery. Source material must enter through the explicit runtime boundary.

What has been constructed

source boundary → preservation and provenance → neutral discovery → extraction → source observations → relationship candidates → recurrence candidates → evidence assembly → verification boundary → deny-by-default public release gate

Each stage is constrained so that derived structure cannot silently become a finding. The current construction is documented on the Machinery page.

Current experimental state

The machinery is still being constructed. Fact-free test code has been written for multiple components, but the complete zero-information machinery baseline has not yet been executed and frozen. No substantive Council source has therefore been admitted to this experiment.

What would count as evidence

Evidence about the experiment must come from observable operation: deterministic processing, preserved provenance, reproducible outputs, successful mechanical tests, correctly enforced boundaries, failures that are recorded rather than hidden, and later performance on supplied source material.

What would not count

A capability is not demonstrated because it was described, coded, intended or claimed. Construction progress is not evidence that the machinery can perform the complete task. Results inherited from an older system are not evidence produced by this experiment.

Next experimental gate

Construction continues until the neutral machinery is complete enough for an end-to-end mechanical test. The verified zero-information baseline must then be frozen. Only after that gate is passed should an authoritative Council source be supplied for the first substantive run.

This page deliberately uses literal system language rather than analogy. It describes the experiment, its controls, its current state and its evidentiary standard.
