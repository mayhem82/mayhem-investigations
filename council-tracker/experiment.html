Experimental Protocol

BUILD STAGE

The Experiment is still under construction. Machinery described here is developmental and must not be treated as a completed, validated or operational experimental system.

A controlled development experiment using a deliberately selected council as the subject.

Experimental control

The machinery receives records from the selected council without a preselected list of matters, actors, issues, patterns, conclusions or investigative targets telling it what to find.

Question being tested

What can the developing investigative machinery independently identify, preserve, structure, connect, analyse and substantiate from the selected council’s records, and how far can those demonstrated capabilities become persistent, governed and reproducible through successive construction, testing, failure, correction and operation?

Controls

The council is deliberately selected and known. What is not preselected is what the machinery should find within its records. Existing investigative conclusions, selected matters, actor lists, issue lists, expected patterns and inherited findings are not supplied as answers to the experiment.

What has been constructed

source boundary → preservation and provenance → neutral discovery → extraction → source observations → relationship candidates → recurrence candidates → evidence assembly → verification boundary → deny-by-default public release gate

Each stage is constrained so that derived structure cannot silently become a finding. The current construction is documented on the Machinery page.

Current experimental state

The machinery is still being constructed. Test code exists for multiple components, but the complete machinery has not yet been executed and validated end to end. No capability is treated as demonstrated merely because it has been designed or coded.

What would count as evidence

Evidence about the experiment must come from observable operation: deterministic processing, preserved provenance, reproducible outputs, successful mechanical tests, correctly enforced boundaries, failures that are recorded rather than hidden, and later performance on supplied source material.

What would not count

A capability is not demonstrated because it was described, coded, intended or claimed. Construction progress is not evidence that the machinery can perform the complete task. Results inherited from an older system are not evidence produced by this experiment.

Next experimental gate

Continue construction until the machinery can undergo an end-to-end mechanical test. Record the result, including failures, before beginning substantive operation against the selected council’s records.

This page describes the experiment literally: its subject, system, controls, procedure, evidence standard and current state. The Philosopher’s Stone is documented separately as an analogy.
