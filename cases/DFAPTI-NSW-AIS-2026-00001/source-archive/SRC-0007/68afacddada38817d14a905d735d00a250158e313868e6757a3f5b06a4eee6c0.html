AXIS Scene Metadata

tip

New: On-device Data Transformation
Transform scene metadata directly on the device using jq expressions.

  • How-to guide
  • Module reference

Axis products produce scene metadata: data about what a device sees. This documentation explains how to consume and use this data when building applications. You can use it for real-time situational awareness, efficient searches, and trend analysis.

Axis devices such as cameras and radars track and collect information about detected objects, including humans, vehicles, and unclassified movement. Data is available under multiple topics to address different use cases. The table below provides an overview of the topics and their properties:

Data sourceSummaryAvailabilitySource
Frame-by-frame object trackingReal-time tracking of objectsACAP SDK, MQTT, RTSP​Fusion Tracker
Consolidated object informationInformation about each object is summarized and delivered once the object leaves the scene.ACAP SDK, MQTTTrack Consolidation
Object snapshotsImage snapshots of tracked objectsACAP SDK, MQTTFusion Tracker

All topics are encoded in JSON following the Analytics Data Format. Most data is also translated into ONVIF-conformant XML over RTSP. See the list of data sources for details about each topic, including its availability and data schema.

Using Data Transformation, you can also transform scene metadata on-device using jq expressions — for example to extract specific fields, filter by object class, or reduce bandwidth before the data leaves the device. See the how-to guide for a step-by-step walkthrough.

AXIS Scene Metadata is supported across various devices, including products with multiple sensor types. For instance, multi-sensor devices like the AXIS Q1686-DLE radar-video device combine sensor outputs to deliver a coherent and comprehensive scene understanding.

For a complete list of supported products, visit the compatible products page. Click View More to see the full list.

To get started, see the Getting Started guide.

To learn about core AXIS Scene Metadata concepts, see the concepts section, which covers object tracking, processing modules, and data framing.
